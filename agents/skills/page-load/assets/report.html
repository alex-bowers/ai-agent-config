Page load waterfall

Each bar starts when Chrome reports the request and ends when it finishes. Its colours show the measured phases where Chrome provides them. Time before sending can include queueing, connection setup and other browser work. Waiting for a response includes network and server time. Neither phase alone proves that another asset blocked the request.
